# Catálogo de películas - Proyecto final LDSW

Esta es una aplicación móvil desarrollada en Flutter que integra Firebase (Authentication y Firestore) y peticiones HTTP.

## Instrucciones para la evaluación

Para probar la aplicación es necesario registrarse con cualquier correo electrónico y contraseña (mínimo 6 caracteres). Cualquier cuenta registrada tiene acceso a la pantalla de administración.

**Credenciales de prueba sugeridas:**
- **Correo:** `admin@test.com`
- **Contraseña:** `123456`

### Funcionalidades:
1. Pantalla de inicio (Login / Registro).
2. Catálogo de películas (lee de Firestore en tiempo real).
3. Detalle de película (título, año, director, género, sinopsis, póster).
4. Administración (agregar y borrar películas).
5. Peticiones HTTP (imágenes cargadas desde URLs).
